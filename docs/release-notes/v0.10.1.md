## 新功能 · What's new

- 🔤 **只按文件名搜**：搜文件时匹配的是名字，“全部”和文件类型下都只看文件名，不再把所在文件夹的名字也算进来——以前搜“合同”，一个叫“合同”的文件夹里所有文件都会冒出来。要按内容搜，按 `Tab` 到“内容”。
  **Name only**: file results match the name alone, under All and under each kind; the folders a file sits in no longer count, so searching 合同 no longer lists everything inside a folder named 合同. To search inside files, press `Tab` to Content.
- 🚫 **排除目录，一次排除干净**：设置 › 搜索范围 里的“不搜索的文件夹”现在是全局的，爬索引时就不进去，历史、手输路径、整盘遍历和内容搜索都照此过滤。已经排掉的目录，索引也会慢慢瘦下来。
  **Exclusions that hold everywhere**: the folders under Settings › Search scope › Folders not searched are now global; the indexer never enters them, and history, typed paths, drive walks and content search all honour them.
- 📁 **每种文件类型还能各排各的**：设置 › 文件类型 里每个类型多了一个“排除路径”按钮，展开就能加文件夹，比如让“代码”别去翻 `node_modules`。类型自己的排除叠加在全局之上，只影响该类型的搜索。
  **Per-kind exclusions**: every kind under Settings › File types has an Exclude paths button; add folders there, say to keep Code out of `node_modules`. They add to the global ones and apply to that kind's searches only.
- 📏 **任务栏搜索窗口记住高度**：从任务栏打开时，窗口的高度不再一会儿是贴着任务栏的高度、一会儿是拖出来更高的那个——拖动预览分栏边框调出的高度会一直记着，空着打开和出结果时都一样高（拖得比任务栏那片还矮时，仍然贴到任务栏为止）。
  **The taskbar search window remembers its height**: opened from the taskbar, the window no longer swings between the height that fills down to the taskbar and the taller one a drag left; the height dragged out of the preview pane's edge is kept with nothing typed and with results alike (a drag shorter than the room still fills down to the taskbar).
- 🎯 **从任务栏打开时居中**：窗口不再对准任务栏上的搜索按钮，而是左右居中对齐屏幕（任务栏在左侧或右侧时上下居中），窗口再也不会因为任务栏按钮的位置而偏向一边。
  **Centred when opened from the taskbar**: instead of lining up over the taskbar's search button, the window centres on the screen sideways (up and down with the taskbar on the left or right), so where the button sits no longer pulls it to one side.
- 📋 **没有预览就讲文件的事**：选中应用或预览不出来的文件时，右侧分栏不再只有一句“这一行没有可预览的文件”，而是显示这个文件的信息——大图标、类型、大小、修改和创建时间、所在位置；已删除的说明它找不到了，只在云端的说明还没下载。设置页、控制面板这类没有对应文件的条目才显示原来的提示。
  **Facts where nothing previews**: selecting an app or a file nothing can show, the pane no longer says only “nothing to preview here”; it shows what is known about the file — a large icon, its type, size, when written and created, where it sits; a gone one says so, a cloud-only one that it has not been downloaded. Entries with no file of their own (Settings pages, Control Panel) keep the plain note.
- 📑 **Office 文档怎么预览，自己挑**：设置 › 结果列表 › 显示与预览 多了“Office 文档怎么预览”：自动（有 LibreOffice 用它，没有用这台电脑上的 Office）、LibreOffice、Office 三选一。没装 LibreOffice 时那一行下有“安装 LibreOffice”按钮，点了就装；预览不出来的时候，分栏会注明“文字版”，不再让人猜为什么没有版式。
  **Choose how Office documents preview**: under Settings › Result list › Display & preview there is now “How Office documents preview” — Automatic (LibreOffice when installed, the Office on this machine otherwise), LibreOffice, or Office. With no LibreOffice, an Install LibreOffice button sits right under it; when a document can only show as text, the pane says 文字版 (text only) instead of leaving the plain look unexplained.
- 🧹 **界面更干净**：结果行的右键菜单和悬停按钮里去掉了“在终端中打开”；设置 › 高级 里的“更新”整块去掉了，检查更新不再有。
  **A cleaner interface**: Open in terminal is gone from the result row's context menu and buttons, and the Update section under Settings › Advanced is gone, checking for updates with it.
